Run `/graft` in any project and it renders that project's Claude Code session as one page: every turn on a timeline, the turns where a decision was made or a commit landed listed as key turns, and a panel for the selected turn with what you asked, what Claude answered and what it committed. One self-contained HTML file, made on your machine, with nothing sent anywhere.

It exists for one job: finding the moment you picked a direction you now want to undo. A long session is unreadable as scrollback. On the timeline, the turn is a click away.

From that turn the page copies two commands. **Copy fork command** starts a new session from that point and leaves the original as it is. **Copy branch command** makes a git branch with the files as they were when the turn began. Nothing on the page runs a command itself.

It never reads a transcript into context, since one can pass 100MB. A small parser reads it line by line and writes only counts back.

**Install**: `claude plugin marketplace add jamesmadson/canon`, then install the `graft` plugin.

**Gotcha**: Claude Code only. It reads the local transcript format, which is undocumented and can change between releases, and the fork command uses a flag Claude Code does not document. If a release breaks either, the skill says so rather than guessing.
