A single, extremely produced skill: describe what you need — a clickable app prototype, a 1920×1080 slide deck, a launch animation, a print-grade infographic — and it ships in 3 to 30 minutes, entirely in HTML. No Figma, no After Effects; the medium is HTML but the output never looks like a webpage pretending to be a deck or a prototype pretending to be a poster.

The task-routing table at the top is the clever part: it reads your request, decides which of nine specialist reference docs to load (storyboard basics for animation, camera-language for motion shots, a screenshot-vs-rebuild decision tree for UI demos), then works like whichever specialist that implies. Give it your logo, colors, and UI screenshots and it reads your brand's voice; give it nothing and twenty built-in design vocabularies keep it out of generic AI-slop territory.

**Install**: `npx skills add alchaincyf/huashu-design`. Verify after installing — this ships with 99 supporting files (references, assets, scripts, demos), and older `skills` CLI versions (≤1.5.15) had a bug that synced only the single SKILL.md file.

**Gotcha**: the skill's own prompts are written in Chinese (the author is a Chinese-speaking developer), though the agent works fine with English tasks — the English README is a parallel translation, not the skill's actual source of truth.
