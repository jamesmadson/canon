The lightest kit here, and the only one pointed at something that already exists. Five skills, led by a three-part audit team that produces one prioritized report.

Its organizing idea is worth stealing even if you never install it: mobile review collapses two different questions — *is this the right design?* and *is it built correctly for the device?* — and mixing them is how opinions start reading as defects and must-fixes get filed as preferences. Keeping them as separate passes with separate output classes, merged only at the end into one fix-order, is what makes the report actionable instead of a list.

The supporting skills aren't there to run separately so much as to give the audit something specific to measure against — a review that says "improve the tap targets" is worth less than one that says 44px and names the file and line. I ran exactly this kit against Canon itself: it found twelve platform defects and a set of design forks I'd been avoiding, and the site you're reading it on is what came out the other side.
