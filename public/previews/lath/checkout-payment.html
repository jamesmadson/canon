Notes
1Back returns to plan choice with Crew, annual and 8 users still selected. Assumed, so nobody re-enters them.
2The summary is short on purpose: plan, billing, users, as briefed. It sits above the money so the sum reads top to bottom.
3Assumed: $24 per user per month, billed yearly, so 8 users × $24 × 12 is $2,304.00. Tax of 8% is also assumed, giving $184.32.
4Decision: the largest thing on the screen is the full year’s total, $2,488.32. Showing only $0.00 due today would repeat the feedback problem of not knowing the real amount.
5The brief asks for the total due today, but a free trial means $0.00 today. Both are shown, with the first charge date. 16 Nov 2026 assumes the trial starts today, 2 Nov 2026.
6Card number, expiry and security code are one group. Expiry and security code share a row to save height.
7Open question: tax depends on location, but the postcode comes after the total. Should the tax line update once the postcode is entered? Until then it is an estimate.
8The only primary action. The label says what it does and names the trial length. The stat above already says nothing is due today, so no extra reassurance is added here.
9Quiet on purpose: a way out, not a competing action. Goes to plan choice, same as the back arrow.
